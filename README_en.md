# YIWALO TUN PRO

**A modern Android tunneling application powered by Xray Core.**

YIWALO TUN PRO is an Android application designed to manage VPN and proxy connections through a simple and modern interface.

This project is based on the open-source ProxyBox project and aims to provide a customized experience under the YIWALO brand.

## Features

- VLESS protocol support
- VMess protocol support
- Shadowsocks protocol support
- Trojan protocol support
- Hysteria2 protocol support
- Import configurations from links
- Import JSON configuration files
- Scan QR codes to import configurations
- Subscription support
- Connection management
- Android TV interface support

**Note:** The features listed above depend on the existing implementation. Additional YIWALO features must be developed in the source code before they become available.

## Requirements

- Android 7.0 or later
- Internet connection
- A valid server configuration

## Installation

Install the APK provided by the project maintainer.

Only install APK files from trusted sources.

## Development

YIWALO TUN PRO is an Android application primarily written in Kotlin and powered by Xray Core.

The source code can be customized to modify the application name, icon, interface, and additional features.

## Building the Application

The project can be built using Android Studio with the required Android SDK and Gradle configuration.
